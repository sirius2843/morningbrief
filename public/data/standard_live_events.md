## 一、已经发生的事件

### 1. 美伊局势出现实质性缓和信号

**发生了什么**

特朗普7/24命令美军暂停对伊朗军事打击（此前连续13天每天批复并执行空袭）。伊朗消息人士通过路透社传话：只要美方停止军事打击，伊朗也将停止军事行动。美国常驻联合国代表7/26确认，为给外交谈判留出空间，特朗普已暂停打击。伊朗外交部发言人7/26确认伊美信息交流仍在持续，斡旋方继续开展工作。7/27凌晨伊朗最高领袖穆杰塔巴·哈梅内伊表态：支持黎巴嫩真主党是伊朗战略政策，维护黎巴嫩领土完整、全面无条件结束以色列对黎军事行动是首要条件。

**为什么值得重视**

此前中东局势是全球风险偏好的最大压制变量——布伦特原油突破100美元/桶，市场定价美联储7月加息概率一度超80%。缓和信号出现后油价从100+急跌至86.67（-14美元/桶，-14%），今晨美股期货全线拉升（纳指期货+1.24%，标普期货+0.66%）。这是7月以来全球大类资产最大的边际变化。

**行业影响**

- 油价回落→通胀预期降温→美联储加息压力减轻→利好全球科技成长方向估值修复
- 航空/交通运输等油价敏感行业成本端改善
- 贵金属避险需求阶段性回落（虽然黄金今晨反弹1%，更多是美元走弱驱动）
- 能源板块短期承压

**周期与主线判断**

属于短期催化事件，不构成中长期主线变化。根本矛盾未解：伊朗最高领袖仍表态坚持抵抗、以色列称伊朗核计划必须终止。缓和可能随时反复。但短期内边际方向对市场有利。

**验证项**

- 美伊是否能在近期达成正式停火协议
- 油价能否稳定在85美元以下
- 特朗普是否改变立场（历史上有反复先例）
- 中东其他势力（胡塞武装、黎巴嫩真主党）是否同步停火

### 2. 证监会释放明确政策底信号

**发生了什么**

证监会上周末召开党的建设暨监管工作座谈会，定调七大要点：①综合施策全力维护市场平稳运行；②更精准实施逆周期调节；③推动中长期资金稳步提升入市规模和比例；④加强应对全球市场波动的政策储备，"筑牢防范外部风险冲击的防波堤"；⑤严查财务造假/内幕交易/操纵市场；⑥扶优限劣促进上市公司做优做强；⑦推进AI在监管中应用。

此前国新控股宣布超500亿增持央企股票+科技+宽基ETF，诚通完成近百亿增持。多家央企、三大险资、地方国资平台同步跟进。

**为什么值得重视**

"防波堤"表述首次出现在证监会正式文件中，标志着监管思路从短期救火转向构建制度性稳定机制。天风策略复盘历史三轮政策底（2012/2018/2024），认为政策底向市场底的传导效率呈现边际递增——2024年超预期政策驱动下市场迅速完成脉冲式上涨并直接开启牛市，调整未破前低。当前指数从高点回调幅度已较大，叠加长线资金积极布局，本轮政策底或将逐步出现。

**行业影响**

- 直接提振市场信心，降低系统性下跌风险
- 中长期资金入市利好大盘蓝筹和优质科技龙头
- 严查违法利好市场生态长期净化

**周期与主线判断**

属于中期制度性利好，不改变短期市场节奏。政策底到市场底之间存在时滞（历史短则数日、长则数周），但下限基本被封住。

**验证项**

- 政治局会议对资本市场的定调
- 中长期资金入市的节奏和规模
- 宽基ETF净申购能否持续
- 融资余额变化（是否止跌企稳）

### 3. 长鑫科技今日科创板上市 — 国产DRAM里程碑

**发生了什么**

国产DRAM龙头企业长鑫科技（688825）今日正式登陆科创板。发行价8.66元/股，实际募资约579亿元（超额配售前），若全额行使超额配售权则募资666亿元，为科创板史上最大IPO。公司预计2026年上半年归母净利润500-570亿元（同比大幅扭亏为盈）。合肥/北京布局3座12英寸DRAM晶圆厂，产能规模国内第一。已进入阿里云/字节跳动/腾讯等头部客户供应链，覆盖服务器、消费电子等多领域。

**为什么值得重视**

长鑫上市填补A股纯DRAM标的空白。DRAM价格自2025年起持续上涨，中泰证券预计2026年业绩有望爆发。市场评估万亿市值，有机构按照2026年净利1500-2000亿元、20倍PE测算市值超3万亿元。

**行业影响**

- 短期：上市首日可能产生资金虹吸效应，科创板/半导体板块日内波动加大
- 中期：为A股半导体产业链提供估值锚，带动设备/材料/封测等配套环节关注度
- 长期：国产存储替代逻辑得到资本市场定价，加速国内上下游协同

**周期与主线判断**

属于半导体主线的验证事件。DRAM景气周期+国产替代双逻辑支撑，不影响主线判断方向，但上市初期的波动需要注意。

**验证项**

- 上市首日收盘价和成交量（市场对存储估值的"定价"）
- 上市后流通市值对科创50/半导体指数的权重影响
- 长鑫H2业绩指引
- 存储现货价格走势

### 4. 三星/SK海力士签9500亿美元芯片超级大单

**发生了什么**

SK集团向包括英伟达在内的美国科技公司供应价值7500亿美元的芯片；三星电子与博通合作开发先进内存芯片制造业务，协议价值超2000亿美元。两项合计9500亿美元（约6.43万亿人民币）。同期黄仁勋发布X平台首条推文，附多家科技巨头签名公开信，为开源AI全面辩护。

**为什么值得重视**

9500亿美元相当于全球半导体年市场规模的大半。这已不是"AI叙事"，而是具有法律约束力的长期供货合同——AI硬件需求正在被真金白银锁定。同时韩元跌至17年新低、外资持续撤离韩国股市，三星/SK的大单说明实体需求与金融市场的短期恐慌之间存在巨大背离。

**行业影响**

- HBM/先进存储方向需求确定性大幅增强
- 存储产业链上下游（设备/材料/封测）受益
- 韩国半导体企业在全球AI供应链中的地位进一步巩固
- 对费城半导体指数暴跌4.25%形成"基本面证伪"

**周期与主线判断**

属于AI硬件主线的强验证事件。产业景气独立于短期股价波动，进一步确认存储/AI算力方向的中期主线地位。

**验证项**

- SK/三星公告原文中的合同条款（交付时间、价格锁定方式、技术规格）
- 英伟达/博通后续财报中的capex和供应链指引
- 存储现货价格的持续走势

### 5. 宁德时代抛出A股史上最大回购方案

**发生了什么**

宁德时代发布半年报：上半年净利润432.84亿元，同比增长41.98%；拟10股派14.11元。同时宣布200-400亿元回购方案（用于注销），为A股史上最大单次回购。动力电池/储能双轮驱动下业绩持续高增。

**为什么值得重视**

A股史上最大单次回购+大额分红，龙头企业在用真金白银表态"我的股票被低估了"。对新能源/电池方向形成情绪支撑。

**行业影响**

- 短期提振新能源/电池板块情绪
- 储能景气度得到龙头业绩验证
- 对上游锂电材料/设备形成正面映射

**周期与主线判断**

属于新能源方向的正面催化，但非郭婉钰当前最核心主线。可作为"其他方向"关注。

**验证项**

- 回购实际执行进度
- 电池级碳酸锂价格走势
- 下半年动力电池排产数据

下半年政策力度和方向。市场预期：进一步加力稳增长、产业政策是主线、基建"六张网"、消费以文旅为抓手、资本市场定调趋于积极。

**将验证什么**

AI资本开支的持续性和云计算增长动能。此前谷歌Q2 capex翻倍，市场关注本轮财报季能否延续。
