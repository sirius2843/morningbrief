# 收盘点评（2026-08-10）

## 盘面综述

周末利好扎堆，今天A股却走出了一个"指数创新高、科技却在失血"的分裂盘面。上证指数收涨0.67%报3966.59点，突破了早盘设定的3950关口但没能摸到4000；中证1000涨0.71%、中证500涨0.64%，小盘继续跑赢沪深300的0.16%；深成指几乎原地踏步只涨0.04%报14316.96点，创业板指反而收跌0.73%报3537.21点，科创50跌0.36%报1737.77点，没能站上早盘关注的1750。全市场4069家上涨、1391家下跌、80家收平，涨停113家、跌停仅8家，赚钱效应其实相当扩散。但成交额只有2.54万亿，比上周五的2.68万亿缩量1446.9亿，回落5.39%——早盘提出的三个观察点里，指数位置过了，科创50的位置没过，量能这一关也没过。

这个组合值得投顾在跟客户沟通时讲清楚：宽度很好，权重很稳，唯独上周领涨的科技赛道熄火了。指数的新高不是科技扛出来的，是消费、周期和中小盘一起把盘面撑住的。

## 外围冲击

周末最大的变量来自美国7月非农。就业人数意外减少2.3万人，而市场预期是增加8万，前两个月的数据还被大幅下修，直接把9月加息的预期浇灭——CME利率期货显示的加息概率从57%骤降至44%。美债收益率应声跳水，两年期跌至4.20%，十年期回到4.65%下方；美元指数跌破100关口报99.59，离岸人民币一度冲到6.74附近，创下三年新高。美股三大指数全线上涨，标普500涨0.62%报7757.64点再创收盘历史新高，道指涨0.28%，纳指涨1.30%，全周三大指数均录得4月中旬以来最大单周涨幅，纳指一周暴涨5.19%。今早日经225涨1.53%、韩国KOSPI涨1.02%接力高开，亚太情绪整体偏暖。

但外围给的信号并不是全面利好科技，而是内部高度分化。光通信方向暴走，Coherent单周涨超40%，费城半导体指数两连阳全周涨超9%，英伟达一周涨超10%；存储芯片却持续承压，西部数据因业绩暴雷跌超13%，SK海力士跌近5%。这一点恰恰解释了今天A股的怪现象：美股光通信涨成那样，A股通信板块却是跌幅第一，跌2.41%还净流出171.74亿。外围没给A股添乱，甚至给了顺风，但A股科技线自己没接住——申万宏源上周末提醒的"电子通信持仓收益已回到盈亏平衡线附近，短期可能就有抛压兑现"，今天几乎是精准兑现。

大宗方面，现货金价周五暴涨2.37%收于4340美元，盘中一度冲上4371美元的七周高位，全周累计上涨7.27%，创今年1月以来最大单周涨幅，今早亚盘在4346美元附近高位企稳；央行7月增持黄金64万盎司，已是连续第21个月买入，且单月增持规模为近两年最大。原油方面WTI周五收涨1.15%报78.18美元，但全周仍跌7.66%，布油今早重回84美元上方。

## 资金方向

资金面呈现的是一次典型的高低切换，而且切换的力度不对等——

| 方向 | 行业 | 涨跌幅 | 主力净额 |
|---|---|---|---|
| 净流入 | 食品饮料 | +2.68% | +26.14亿 |
| 净流入 | 基础化工 | +1.48% | +20.21亿 |
| 净流入 | 医药生物 | +1.35% | +18.54亿 |
| 净流入 | 农林牧渔 | +3.07% | +15.25亿 |
| 净流入 | 银行 | +0.30% | +9.31亿 |
| 净流出 | 电子 | -0.37% | -187.53亿 |
| 净流出 | 通信 | -2.41% | -171.74亿 |
| 净流出 | 计算机 | -0.21% | -11.46亿 |
| 净流出 | 建筑材料 | +0.20% | -11.30亿 |
| 净流出 | 机械设备 | +0.07% | -9.19亿 |

这里有个细节需要点透：电子和通信两个行业合计流出359.27亿，而流入前五加起来只有89.45亿，量级完全不匹配，再叠加全市场缩量1446.9亿，说明今天并不是"科技的钱原封不动搬到了消费"，而是一部分资金选择了离场观望，剩下的存量资金在低位方向上做了扩散。主力资金整体是净流出的，但涨停113家、上涨4069家——承接盘主要来自中小市值和被动资金，不是主力加仓。这个区别决定了明天的定性：如果只看涨跌家数会过于乐观，真正要盯的是科技线的流出速度会不会收敛。

## 强弱榜

强势方向清一色是低位的消费与周期，农林牧渔涨3.07%居首，食品饮料涨2.68%，纺织服饰涨2.21%，煤炭涨2.20%，社会服务涨2.01%，房地产涨1.74%对应北京非京籍社保满1年即可购房的地产新政，有色金属涨1.91%跟随黄金周涨7.27%的强势。弱势方向则集中在上周的领涨赛道，通信跌2.41%领跌，电子跌0.37%，计算机跌0.21%，非银金融跌0.15%——全场只有这四个行业收绿，其余27个一级行业悉数飘红。值得留意的一处背离是有色金属虽然涨1.91%，主力资金却小幅净流出1.26亿，金价创阶段新高但资金没有追进去，说明黄金股这一波更多是跟随商品价格的被动上涨，而非机构主动加仓。

## 趋势判断

眼下的格局是外部顺风、内部筹码逆风的对冲。非农爆冷带来的流动性预期改善、美元跌破100、人民币升破6.74，这些对新兴市场都是实打实的利好，国内7月CPI同比涨0.5%、PPI同比涨3.5%双双回落，通胀压力减弱意味着货币政策空间被保留下来，加上北京地产新政落地，政策底的托举是清晰的。压制来自另一端：科技板块经过上周沪指涨2.81%、创业板涨6.55%的快速修复后，交投拥挤度并没有回落，中信证券此前提示浮亏压力集中在科技成长与小微盘需要时间消化，今天电子通信近360亿的流出就是这句话的注脚。

所以今天的缩量不宜简单解读为"利好出尽"。市场对周末的多重利好是接住了的，只是接的方式不是追高科技，而是把仓位换到了估值和拥挤度都更低的位置。这种切换在中报密集披露的8月中下旬有其合理性——华泰证券提示中报期是检验反弹成色的窗口，建议锚定中报均衡配置，这个思路和今天的资金动向是吻合的。操作上，指数层面不必悲观，3950已经站上，但追高科技的性价比在下降，若科技线明天继续放量流出而量能无法回到2.6万亿之上，反弹升级为趋势的判断就要往后推。相对稳妥的思路是让仓位向有中报业绩支撑、机构持仓又处于低位的方向倾斜，同时保留对科技的底仓而非在拥挤位置加码。

## 行业扫描

食品饮料今天是资金和涨幅的双料主角，板块ETF口径上涨2.36%，易方达中证消费50ETF涨2.81%领涨，一级行业涨2.68%并以26.14亿净流入位居全场第一。这个位置的吸引力恰恰来自此前的极度冷清——国金证券在二季度基金持仓分析中指出板块已全面转向低配、白酒仓位大幅回落，而最新的行业周报里，开源证券提到茅台提价深化了主动权、酵母蛋白产业化在加速，国金证券也观察到高端酒批价回升并建议关注稳健龙头的配置价值。万联证券对1H2026业绩预告的综述则显示食饮业绩有所回暖但行业持续分化。低配的筹码结构叠加批价企稳，是开源证券判断"资金与基本面共振、底部布局窗口已现"的主要依据，今天的资金流向可以看作这一判断的初步验证，但白酒的真正考验仍在中报和中秋旺季的实际动销。

军工板块上涨2.01%，南方国证航天航空行业ETF涨2.93%领涨，成交16.7亿，一级行业口径的国防军工涨1.69%、净流入5.22亿。这个方向目前最有意思的是筹码的极致反差：中航证券在7月底的周报中指出，公募基金军工持仓创下2023年以来新低，而外资军工持仓却创下新高，内资撤离与外资进场同时发生。基本面上，中航证券的军工材料月报对2026年下半年的表述已经从谨慎转为"开始乐观"，行业周报延续了高质量推进国防和军队现代化的主线。低空经济作为衍生方向也有增量，金元证券提到全国低空经济标准化技术委员会拟成立，标准化推进往往是产业从概念走向订单的前置信号；东吴证券则关注到长十乙首飞回收成功、星座建设逐步加速。在公募持仓处于历史低位的背景下，军工的向上弹性主要取决于订单能否兑现到报表。

煤炭钢铁上涨1.82%，国泰中证煤炭ETF涨2.27%，一级行业煤炭涨2.20%，不过主力净流入仅1.62亿，涨幅与资金的匹配度并不高，更像是低位红利属性带来的估值修复而非资金集中做多。研报层面近期非常密集，信达证券今天的周报直接以"供给紧煤价升、板块韧性偏强"定调，此前也持续提示港口库存去化；开源证券认为供给约束延续价格支撑、旺季需求释放推动煤价上行；国金证券指出动力煤供需矛盾显现、涨价在加速，同时提示焦煤存在预期差；山西证券则观察到炼焦煤偏强运行、焦炭第三轮提降已经落地，动力煤与焦煤走势有所分化。需要提醒客户的是，山西证券早前明确提示8月进入中报季后要关注业绩兑现，煤炭的高股息逻辑成立但业绩弹性有限，更适合作为组合里的稳定器而非进攻品种。

有色贵金属上涨1.70%，工银瑞信中证有色金属矿业主题ETF涨2.55%，54.0亿的成交额在今天扫描的五个方向里最大，但一级行业口径的主力资金小幅净流出1.26亿，形成价格强、资金弱的背离。宏观层面的支撑是充分的：加息预期缓解叠加美元跌破100，金价全周大涨7.27%，央行连续21个月增持黄金。工业金属这条线的逻辑比贵金属更扎实，中邮证券认为供给扰动升级、看好铜价突破新高，中银证券也指出铜矿供给刚性将支撑铜价中枢上移。小金属方向出现了新的催化，国金证券在双周谈中提到钨、锆受益于反制措施，流动性反包利好锡，并单独强调加息预期缓解下钨的战略属性再度强化。不过大同证券的判断偏中性，认为加息预期降温后各板块以震荡运行为主，考虑到今天资金并未跟进，短期更适合逢回调布局而非追高。

传媒游戏上涨1.47%，国泰中证影视主题ETF涨2.59%领涨，一级行业传媒涨1.44%、净流入7.5亿。这个方向今天的意义超出板块本身——在电子、通信、计算机集体失血的同一天，同属AI叙事的传媒却能收红并获得资金流入，说明市场并没有否定AI这条主线，只是把定价重心从算力硬件切向了应用端。研报的密集程度印证了催化确实在增加，开源证券今天的周报提到国产模型、AI办公、物理AI催化不断，同时电影暑期档在升温；国信证券关注到Seedance 2.5与DeepSeek V4 Flash发布，建议持续跟踪AI应用及游戏板块的底部机会；万联证券提到月之暗面全量开源Kimi K3以及2026年1-6月中国游戏产业报告的发布；华鑫证券和华龙证券则从更长的视角讨论AI时代内容公司的护城河、国产大模型与IP出海。对客户而言，传媒的位置和拥挤度都远低于算力硬件，是参与AI主线时相对舒服的替代路径，但内容行业的业绩兑现节奏偏慢，需要以季度而非周度的耐心去看。
