## 二、隔夜事件点评

### 事件1：苹果暴跌7.35%，存储链7月血崩，全球"内存荒"反噬终端
**发生了什么**：苹果财报考评"史上最佳二季度"（营收1094亿美元、+16%），但下季指引增速9%~11%低于华尔街12%预期，叠加内存等核心零部件涨价被迫上调产品零售价、毛利率承压，市场用脚投票单日蒸发约3600亿美元。与此同时，美光 -5.9%、铠侠7月 -53%、闪迪 -46%——存储板块7月集体崩塌。
**市场怎么定价**：资金从"AI叙事最弱"的苹果撤出，集中涌向云AI兑现更硬的亚马逊（+15%）。本质是全球AI数据中心抢占了约七成存储产能，手机/PC分到的三成被涨价，连苹果都"拿不到货、扛不住价"。
**A股影响（中性偏多国产存储，警惕消费电子成本）**：长鑫LPDDR6送样、下半年量产在即，全球存储紧缺 + 国产替代逻辑对长鑫产业链是实质催化；但存储涨价已传导至终端，消费电子链（果链、PC）成本端承压，需甄别。短期看，苹果暴跌对A股果链情绪偏利空，对存储自主可控偏利多。

### 事件2：美伊戏剧性缓和 + OPEC+增产，油价周一暴跌近7%
**发生了什么**：特朗普8/1称"同意取消对伊朗军事打击"，8/2又抛出"霍尔木兹已有协议、3日谈判"说法（伊方驳斥为"谎言"，称海峡未达成任何协议）；叠加OPEC+批准9月起日均增产18.8万桶、自愿减产全面回撤。双重打压下，周一亚市WTI跌破80美元、布伦特一度 -7.3%。
**市场怎么定价**：地缘风险溢价被快速抽离，美股期货（标普+0.4%、纳指100+0.78%）、黄金、加密集体拉升，油价破位下行。但霍尔木兹通航风险未消散（油轮仍遇袭、伊朗官方口径反复），油价下方仍有反复。
**A股影响（结构分化）**：原油破位 → 石油石化、油服承压（7/31石化已 -1.05%）；航空、化工（成本端）、航运边际利好；通胀预期回落 + 美债利率缓和，对高估值成长估值端是正向。整体是"成本端让利、上游承压"的组合。

### 事件3：国内政策与产业催化密集——算力网、电网、核电、适度宽松齐发
**发生了什么**：发改委测算"十五五"算力网建设新增直接投资4万亿元；国常会核准辽宁庄河一期等4个核电项目（总投资超1700亿元）、强调高质量建设新型电网与物流网；央行下半年工作会议定调"继续实施适度宽松货币政策、适时调整工具、保持流动性充裕、谋划增量政策"；长鑫LPDDR6接近研发验证尾声。另据Wind，7月股票ETF净流入4778亿元创单月历史新高。
**市场怎么定价**：政策底 + 流动性底明确，长线资金（ETF逆势扫货）在调整中加速布局。卖方普遍判断"7月调整是拥挤交易修正而非去杠杆冲击"。
**A股影响（利多算力/电网/核电/国产存储）**：算力基建（IDC、液冷、电力设备）、新型电网、核电产业链直接受益政策定调；长鑫量产节点强化国产存储关注。但需注意——政策催化≠即刻主升，8月下旬中报 + 英伟达财报窗口才是趋势性反弹的关键验证点。

### 事件4：日韩剧烈波动 + 美日联手干预日元，亚洲风险偏好仍脆弱
**发生了什么**：韩股7/31暴涨17.91%（历史最大单日涨幅、SK海力士涨停）后，8/3低开低走跌近4.7%；日本财务省宣布与美联手实施近30年来最大规模协调外汇干预以稳定日元。
**市场怎么定价**：极端波动反映亚洲高beta资产（尤其存储链）筹码极不稳定，杠杆资金在韩股极端位置快速收缩。美日干预日元短期稳汇率，但亚洲市场宽度并未确认隔夜美股反弹。
**A股影响（压制权重开盘，但人民币强势对冲）**：A50偏弱（-0.4%）是今日权重端最直接的偏弱信号，指数高开意愿不足；不过离岸人民币保持6.75强势、部分对冲A50回落压力。对A股半导体/存储是情绪高波动映射，跟踪承接质量比看指数高低开更重要。

### 事件5：券商晨会一致偏多修复，但锚点落在"拥挤度"
**发生了什么**：中信"调整基本结束、8月修复可期"（拥挤交易修正而非韩国式去杠杆，杠杆安全、ETF持续流入）；华泰"科技交易底初现"；开源"拥挤度是后续市场节奏的核心锚点"；国联民生"年度级别买入机会"。配置共识：科技反弹优先围绕业绩确定性高的半导体设备，同时增配能化、有色、非银、创新药。
**市场怎么定价**：机构从"恐慌"切向"寻找修复"，但普遍强调不追高、看拥挤度回落与业绩兑现，方向从纯AI向"AI+能化+低位改善"扩散。
**A股影响（偏多，但操作纪律前置）**：情绪底修复方向明确，但7月双创指数月跌超20%、科技短期涨幅快，追高性价比下降。机构口径统一指向"重结构、看业绩、控拥挤"。

## 四、今日关注

**盘前定调：中性偏多、震荡修复，防高开回落。** 外盘是"美股偏暖、美债利率回落、人民币强势、油价破位"的组合，对成长估值与成本端友好；但A50偏弱（-0.4%）、日韩剧震（韩-4.7%）压制权重与高开意愿，今天更该看科技强线的承接质量，而非只看指数高低开。

**今日关注方向**：
1. **国产存储 / 先进封装**：长鑫LPDDR6送样 + 全球存储紧缺，产业节点清晰；但警惕苹果暴跌引发的全球存储链情绪波动，跟踪承接而非追高。
2. **算力基建 / 电网 / 液冷 / 核电**："十五五"算力网4万亿 + 新型电网 + 核电核准，政策密集定调，是中期确定性方向。
3. **油价下跌受益 + 人民币强势**：航空、化工（成本端）、航运边际改善；人民币6.75强势支撑核心资产与外资偏好。

**操作思路一句话**：量能若不能稳在2.5万亿上方，反弹高度受限——优先跟踪业绩确定性强、筹码结构健康的科技细分（半导体设备、算力），警惕纯概念高位品种的获利兑现，别在一致性最高时接最后一棒。
