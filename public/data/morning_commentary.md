# 早盘必读（2026-08-04）

隔夜美股科技线暴力反攻，纳指涨超2%创近月最佳单日表现，叠加美伊谈判压制油价大跌5%，全球risk-off情绪显著退潮。A股昨日缩量调整但赚钱效应不差——4000+个股飘红，问题是科创50独自暴跌5%，科技线内部分化到了极致。今天的关键问题是：隔夜外盘科技大反弹能不能把科创50从坑里拉出来？

**隔夜外盘**

隔夜美股三大指数集体大涨，道指收涨1.32%报53178点再创收盘新高，标普500涨1.48%报7600点，纳指涨2.13%报25914点。科技七巨头指数飙升3.6%创3月底以来最佳单日表现——Meta涨超6%、微软涨近5%、亚马逊和谷歌涨超4%、英伟达涨近3%，仅苹果逆势跌1.78%。费城半导体指数开盘一度暴跌，随后低开高走收涨1.05%，闪迪涨超6%、高通涨超2%，存储板块上演深V。中概股涨跌互现，金龙指数涨0.75%，阿里巴巴涨超4%领跑。欧洲同步走强，德国DAX涨1.59%，法国CAC涨1.22%。大宗方面，美伊对话消息重挫油价——WTI跌5.11%报80.34美元，盘中一度跌超7%；布伦特跌4.73%报83.77美元。黄金报4052美元基本持平，伦铜微涨0.33%。汇率端美元指数报99.96微涨0.18%，离岸人民币6.7583小幅走贬54bp。

亚太早盘跟涨积极。日经225高开0.38%报63995点，韩国KOSPI高开1.5%报6351点，SK海力士涨超2%、三星电子涨超1%。A50期货和恒生期货盘前均小幅走高，整体外围环境对A股偏友好。

**事件扫描**

隔夜最大的变量是美伊局势出现缓和信号。特朗普称美伊谈判已启动，第一阶段开放霍尔木兹海峡"最快明天完成"，第二阶段讨论无核化。尽管伊朗官方否认与美国直接谈判、仅承认与阿曼就海峡问题对话，但市场用脚投票——WTI盘中暴跌7%以上，全球风险偏好明显回升。这对A股有两层影响：一是能源和航运板块的避险溢价会快速消退，煤炭、石油石化短线承压；二是整体风险偏好修复利好科技成长估值，尤其此前受油价和地缘压制的方向。

国内政策面继续加码。国务院公布修订后的《集成电路布图设计保护条例》，10月15日起施行，增加独创性声明要求，对半导体知识产权保护形成制度升级。发改委和能源局印发新型电力系统"十五五"规划，2030年新型储能3亿千瓦、非化石能源发电占比50%，特高压十四五在建规模两倍——电力设备和电网方向获顶层文件加持。证监会对港合作10条落地，涵盖港股回A上市、ETF快速注册等，对券商和港股相关品种形成情绪提振。

产业层面，储能产业链18天内7家企业集体涨价，涨幅2%-30%，行业从"以价换量"转向"以质定价"，亿纬锂能、盛弘股份等核心标的定价权改善。宁德时代中期分红61.8亿元，延续高分红策略。船舶行业上半年新接订单同比翻倍，景气度维持高位。

资金方向非常明确：避高就低。主力净流入前五——通信+39.7亿、电力设备+20.7亿、公用事业+16.9亿、基础化工+9.2亿、银行+8.3亿；净流出前五——电子-98.2亿、建筑材料-25.6亿、传媒-9.3亿、医药生物-8.6亿、有色金属-6.3亿。电子一家的流出量相当于前五流入总量，科技线内部抛压集中释放。行业涨幅方面，综合+2.64%、环保+2.40%、轻工制造+1.38%领涨，低位和防御品种接力明显。

**今日关注**

隔夜美股科技大反弹和费半深V反转，对A股科技线构成直接情绪支撑。但关键不在于外盘涨了多少，而在于科创50昨天-5%的阴线能不能被承接住——如果早盘高开后量能跟不上、再度回落，那科技线的二次探底就还没走完；如果能放量站稳，短期超跌修复就值得认真对待。

方向上看两条线：一是半导体和存储的超跌反弹机会，费半V型反转+闪迪涨6%的情绪传导，叠加集成电路条例修订的政策催化，关注设备、材料、存储方向的承接力度；二是新型电力系统规划驱动的电网设备、储能方向，政策窗口明确、资金已有先手流入，持续性优于纯题材轮动。

操作上控制仓位，科技线不追高、等底部确认信号。低位消费、红利和公用事业方向资金持续流入，作为防御底仓的性价比仍在。
